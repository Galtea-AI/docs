---

<Warning>
  You are reading the docs of Galtea 5.22. [Read this page in the latest version](/sdk/api/storage/read).
</Warning>

Use this when the bytes go straight into a request of your own: the base64 image or document part a multimodal model takes, or a parser that reads from memory. Reach for [`download()`](/v5.22/sdk/api/storage/download) instead when the file is meant to stay on disk, or when a library you call only takes a path.

An input file is capped by the total of one input: 20 MB by default, and a deployment can [raise it](/v5.22/concepts/product/version/session/content-parts). `read()` holds the whole file in memory, so it is safe up to the total that your environment sets. Where that total is above the memory of your process, use [`download()`](/v5.22/sdk/api/storage/download), which streams the file to disk.

## Returns

Returns the file's `bytes`.

## Example

```python
document_bytes = galtea.storage.read(test_case.input_files[0])
encoded = base64.b64encode(document_bytes).decode()
```

Inside an agent callback, the files of the current turn arrive as [`input_data.input_files`](/v5.22/sdk/api/agent/input#reading-attached-files), so the same call reads the document the test case attached.

## Parameters

<ResponseField name="file" type="string | AttachedFile" required>
  The file to fetch: an [`AttachedFile`](/v5.22/sdk/api/test-case/upload-input-file) read from `test_case.input_files`, `trace.input_files`, `input_data.input_files` or `trace.actual_output_files`, or the URI of any file this organization uploaded. Those lists also hold a [file part of your own](/v5.22/concepts/product/version/session/content-parts#your-own-parts), which this call cannot fetch: fetch it with your own client.
</ResponseField>

## Errors

| Error | Cause |
|-------|-------|
| `ValueError` | No URI was given, or the value names a file on this machine. |
| `Exception` | The link expired, the platform did not find the file (a file of another organization, or a file part of your own), the platform returned no link, or the transfer failed. |

<Note>
  A failed read raises instead of returning `None`, and the message never contains the
  presigned link.
</Note>
