## Returns
Returns a [Dataset](/v5.21/concepts/product/dataset) object for the given dataset ID.

## Example
```python
dataset = galtea.datasets.get(dataset_id=dataset_id)
```

## Parameters
<ResponseField name="dataset_id" type="string" required>
