## Overview

`galteactl` is the program that runs the install steps of a self-hosted or private Galtea deployment. It ships inside the installer bundle, one signed archive per release, `galtea-installer-<version>.tar.gz`. The bundle holds the `galteactl` builds, the Terraform modules and the package of each cloud.

Each release has three files, next to each other:

- `galtea-installer-<version>.tar.gz`, the bundle.
- `galtea-installer-<version>.tar.gz.sha256`, its checksum.
- `galtea-installer-<version>.tar.gz.sig`, a signature of the bundle made with the key that signs Galtea's container images.

`galteactl update --installer` already checks the checksum you give it and the signature. This page is for a person who also wants to check them by hand. No SBOM ships with the bundle.

## Requirements

- cosign 2.0 or later.
- The AWS CLI and the read key profile of your delivery package guide (`galtea-artifacts` below), to copy the files. Copy each file by its exact name.

## The public key

Save this key as `image-signing.pub`. The same file is in each package of the bundle as `policy/image-signing.pub`, and `galteactl` embeds it. Compare the copies before you trust any of them.

```text
-----BEGIN PUBLIC KEY-----
MFkwEwYHKoZIzj0CAQYIKoZIzj0DAQcDQgAE7fG9qQZ+DndffVmQPaZT5/jIg8Uu
OVy5xcVBKSkk7xmsR/HzUC+4FWhsm/OJmUSxNY7oYnSev7pq2Cb1P07Bzw==
-----END PUBLIC KEY-----
```

## Verify a bundle

Set the release (for example `1.0.0`) and the checksum of the release email.

```bash
V=1.0.0
SHA256=<checksum of the release email>
F="galtea-installer-$V.tar.gz"
mkdir -p /tmp/galtea-installer-$V && cd /tmp/galtea-installer-$V
for f in "$F" "$F.sha256" "$F.sig"; do
  aws s3 cp --profile galtea-artifacts "s3://galtea-delivery-packages/installer/$V/$f" .
done
echo "$SHA256  $F" | sha256sum -c -
sha256sum -c "$F.sha256"
cosign verify-blob --key image-signing.pub --insecure-ignore-tlog=true --signature "$F.sig" "$F"
```

Expected output: `galtea-installer-1.0.0.tar.gz: OK` twice, then `Verified OK`. If a command prints anything else, do not unpack the bundle, and write to [support@galtea.ai](mailto:support@galtea.ai).

<Note>
  The signature proves that a Galtea release job made the file. The signing key lives in AWS KMS and never leaves it. The signature is not in a transparency log, so the public key alone verifies it: that is why the command ignores the log.
</Note>
