The User Groups Service in the Galtea SDK allows you to manage [user groups](/v5.16/concepts/user-group) for your organization.
This Service is exposed by the `galtea.user_groups` object.

<Info>
  Remember that we will be using the `galtea` object. More information [here](/v5.16/sdk/api/galtea).
</Info>

## Quick Example

First, initialize the Galtea SDK:
```python
galtea = Galtea(api_key="YOUR_API_KEY")
```

Create a user group:
```python
user_group = galtea.user_groups.create(
    name="quality-reviewers-" + run_identifier,
    description="Team responsible for reviewing output quality",
)
```

List user groups:
```python
user_groups = galtea.user_groups.list(
    sort_by_created_at="desc",
    limit=10,
)
```
