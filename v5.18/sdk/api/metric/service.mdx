The Metrics Service in the Galtea SDK allows you to manage [metrics](/v5.18/concepts/metric) for evaluating your products.
This Service is exposed by the `galtea.metrics` object.

<Info>
  Remember that we will be using the `galtea` object. More information [here](/v5.18/sdk/api/galtea).
</Info>

## Quick Example

First, initialize the Galtea SDK:
```python
galtea = Galtea(api_key="YOUR_API_KEY")
```

Create a metric:
```python
metric = galtea.metrics.create(
    name=metric_name,
    evaluator_model_name="GPT-4.1",
    source="partial_prompt",
    judge_prompt="Evaluate if the actual_output is polite.",
    evaluation_params=["input", "actual_output"],
    description="Checks politeness",
)
```

List all metrics:
```python
metrics = galtea.metrics.list(limit=20)
```

Get a metric by name:
```python
metric = galtea.metrics.get_by_name(name=metric_name)
```
