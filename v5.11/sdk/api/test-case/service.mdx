The Test Case Service in the Galtea SDK allows you to manage [test-cases](/v5.11/concepts/product/dataset/test-case) for evaluating your products.
This Service is exposed by the `galtea.test_cases` object.

<Info>
  Remember that we will be using the `galtea` object. More information [here](/v5.11/sdk/api/galtea).
</Info>

## Quick Example

First, initialize the Galtea SDK:
```python
galtea = Galtea(api_key="YOUR_API_KEY")
```

Create a test case:
```python
test_case = galtea.test_cases.create(
    dataset_id=dataset_id,
    input="What is the capital of France?",
    expected_output="Paris",
    context="Geography facts",
    variant="original",
)
```

List test cases:
```python
test_cases = galtea.test_cases.list(dataset_id=dataset_id, limit=20)
```

Get a test case by ID:
```python
test_case = galtea.test_cases.get(test_case_id=test_case_id)
```
