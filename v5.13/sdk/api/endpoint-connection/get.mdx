## Returns
Returns an [Endpoint Connection](/v5.13/concepts/product/endpoint-connection) object for the given ID.

## Example
```python
endpoint_connection = galtea.endpoint_connections.get(endpoint_connection_id=endpoint_connection_id)
```

## Parameters
<ResponseField name="endpoint_connection_id" type="string" required>
  The ID of the endpoint connection to retrieve.
</ResponseField>
