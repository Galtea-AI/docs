## Returns
Returns a [Version](/v5.14/concepts/product/version) object for the given version ID. The object carries the version's `number`, its product-local identity. On a self-hosted deployment older than version numbers, `number` is `None`.

## Example
```python
version = galtea.versions.get(version_id=version_id)
```

## Parameters
<ResponseField name="version_id" type="string" required>
  The ID of the version you want to retrieve.
</ResponseField>
