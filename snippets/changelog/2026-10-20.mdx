## Link One Dataset to Several Specifications

A [dataset](/concepts/product/dataset) can now link to several [Specifications](/concepts/product/specification) of its product. An evaluation that names several of them runs the dataset once and scores it with the metrics of all of them.

- **In the SDK**, pass `specification_ids` to [`datasets.create()`](/sdk/api/dataset/create) and [`datasets.update()`](/sdk/api/dataset/update). `specification_id` is deprecated and holds the oldest link.
- **Agent runs need SDK 5.11.0 or later.** An older SDK reads only the oldest link of a dataset, so [`evaluations.run()`](/sdk/api/evaluation/run) with an `agent` skips a dataset linked to several specifications for every specification but its oldest one.
