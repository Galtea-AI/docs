description: "Link tests to a specification."
---

## Example
```python
galtea.specifications.link_tests(
    specification_id=specification.id,
    test_ids=[test_id],
)
```

## Parameters
<ResponseField name="specification_id" type="string" required>
  The ID of the specification to link tests to.
</ResponseField>
<ResponseField name="test_ids" type="list[string]" required>
  List of test IDs to link to the specification.
</ResponseField>
