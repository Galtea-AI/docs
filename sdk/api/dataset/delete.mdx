---
title: 'Deleting Dataset'
sidebarTitle: "Delete"
description: "Delete a specific dataset by its ID."
---

## Example
```python
galtea.datasets.delete(dataset_id=dataset_id)
```

## Parameters
<ResponseField name="dataset_id" type="string" required>
  The ID of the dataset you want to delete.

  <Note>Deprecated alias: `test_id`.</Note>
</ResponseField>
