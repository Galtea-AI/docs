---
title: "Unlink Products"
sidebarTitle: "Unlink Products"
description: "Remove products from a user group."
---

Only an OWNER or ADMIN can unlink products from a user group. Galtea stores this link, but it does not restrict product access by group yet.

## Example
```python
galtea.user_groups.unlink_products(
    user_group_id=user_group_id,
    product_ids=[product_id_2],
)
```

## Parameters
<ResponseField name="user_group_id" type="string" required>
  The ID of the user group.
</ResponseField>
<ResponseField name="product_ids" type="list[string]" required>
  List of product IDs to remove from the group.
</ResponseField>
