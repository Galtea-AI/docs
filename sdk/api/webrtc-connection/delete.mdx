## Example
```python
galtea.web_rtc_connections.delete(web_rtc_connection_id=web_rtc_connection_id)
```

## Parameters
<ResponseField name="web_rtc_connection_id" type="string" required>
  The ID of the WebRTC connection to delete.
</ResponseField>
