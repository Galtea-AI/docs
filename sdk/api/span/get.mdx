## Returns
Returns a [Span](/concepts/product/version/session/span) object.

## Example
```python
span = galtea.spans.get(span_id=span_id)
```

## Parameters
<ResponseField name="span_id" type="string" required>
  The unique identifier of the span to retrieve.
</ResponseField>
