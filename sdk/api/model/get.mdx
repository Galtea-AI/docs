---

## Returns
Returns a [Model](/concepts/model) object for the given ID.

## Example
```python
model = galtea.models.get(model_id=model_id)
```

## Parameters
<ResponseField name="model_id" type="string" required>
  The ID of the model to retrieve.
</ResponseField>
